SDT Backup 개인정보처리방침

이 정책은 SDT Backup 개인 연구용 macOS 백업 도구와 안내 웹사이트에 적용됩니다.

1. 목적과 기능

사용자가 지정한 SDT 연구파일을 사용자의 Google Drive 보관함에 저장하고, 파일 목록·크기·해시와 백업 스냅샷으로 무결성을 검사하며, 사용자 요청 시 복원하기 위해 Google Drive API를 이용합니다.

2. 처리 대상 데이터

  • 백업 대상으로 선택한 연구파일의 내용, 경로, 파일명, 크기 및 체크섬
  • 백업 시각, 결과, 스냅샷과 복구에 필요한 파일·폴더 메타데이터
  • OAuth 인증 정보는 사용자의 맥에 설치된 rclone이 로컬 설정으로 보관·관리합니다. 이 공개 사이트에서는 인증 토큰을 수집하지 않습니다.

3. Google 권한과 이용 제한

rclone 설정에서 Google Drive 전체 접근 범위(https://www.googleapis.com/auth/drive)를 선택할 수 있습니다. 백업 도구는 지정된 SDT 보관 폴더를 사용하도록 구성되며, 이 권한을 광고·마케팅·사용자 프로파일링에 이용하지 않습니다.

4. 보관 장소와 보존 기간

백업 파일은 사용자가 소유·관리하는 Google Drive에, 프로그램 설정과 로그는 사용자 컴퓨터에 보관됩니다. 백업 스냅샷과 파일은 사용자가 직접 삭제할 때까지 남을 수 있습니다. 권한을 철회하거나 도구를 제거해도 이미 업로드된 Drive 파일이 자동으로 삭제되지는 않습니다.

5. 외부 제공과 데이터 공유

별도의 SDT 운영자 서버로 Google Drive 데이터나 인증정보를 수집하지 않습니다. 백업 데이터를 판매하거나 외부 광고업체와 공유하거나 AI 모델 학습에 이용하지 않습니다. Google Drive와 GitHub Pages는 각자의 서비스 운영 및 정책에 따릅니다.

6. 공개 웹사이트

이 정적 사이트에는 로그인 양식, 자체 분석용 스크립트나 광고 추적기를 포함하지 않습니다. GitHub Pages 호스팅 과정에서 GitHub가 기술적 접속 데이터를 처리할 수 있으며, 해당 내용은 GitHub 개인정보 보호정책을 참고하세요.

7. 접근 철회 및 데이터 삭제

사용자는 Google 계정의 연결된 앱 관리에서 언제든 권한을 철회할 수 있습니다. macOS의 백업 실행 서비스는 직접 비활성화할 수 있고, 백업 파일은 사용자가 Google Drive에서 직접 삭제할 수 있습니다.

8. 보안 유의사항과 문의

백업 도구는 비밀키·인증 파일 등으로 식별되는 파일을 제외하도록 설계되었지만 파일 내용에 포함된 모든 민감정보를 자동 탐지하는 것은 아닙니다. 백업 대상으로 지정한 폴더에는 비밀정보나 거래소 계정 자료를 저장하지 마세요.

개인 프로젝트 관련 문의는 GitHub 이슈에서 할 수 있습니다. 공개 이슈에는 개인 정보와 인증정보를 게시하지 마세요. 정책은 이 페이지를 수정해 갱신합니다.

Privacy Policy (English)

Effective October 9, 2026. SDT Backup is a locally operated macOS tool that uses rclone and the Google Drive API to back up selected research files to the user's own Google Drive. It handles file contents, names, checksums and snapshot metadata for backup, verification and requested restoration. The configured OAuth scope may allow broad access to Google Drive even though the backup program operates on the designated archive folder.

OAuth tokens are managed by rclone on the user's computer; this informational website does not receive them or the research files. SDT Backup does not run a separate data-collection server and does not sell, advertise with, or use backed-up content for AI training. Backups remain in the user's Drive until deleted. Revoking access or removing the app does not automatically delete already stored files.

Users may revoke permission through Google Account connections and delete their Drive backups directly. The public site has no custom analytics or ad tracking; GitHub may process standard hosting logs under its own policy. Questions: GitHub Issues (do not post credentials).
